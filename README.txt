OFFLINE ΛΕΙΤΟΥΡΓΙΑ
------------------
1. Ανέβασε όλα τα αρχεία στο GitHub Pages / hosting.
2. Άνοιξε την εφαρμογή μία φορά με internet.
3. Περίμενε να γράψει κάτω αριστερά: ONLINE · OFFLINE READY.
4. Μετά μπορείς να κλείσεις internet και να ξανανοίξεις την εφαρμογή.

Χωρίς internet λειτουργούν:
- άνοιγμα εφαρμογής,
- GPS της συσκευής,
- HUD,
- υπολογισμοί,
- WPT / διαδρομές,
- Test Mode,
- ημερολόγιο αποστολής,
- αποθηκευμένες περιοχές χάρτη.

Χωρίς internet δεν ανανεώνονται:
- METAR,
- αναζήτηση περιοχής,
- νέο αυτόματο ΤΦ.

Για ΤΦ χωρίς σύνδεση χρησιμοποιείται αποθηκευμένο ΤΦ της ίδιας ημερομηνίας
ή ζητείται Manual ΤΦ.

Ο γενικός χάρτης Ελλάδας/Βαλκανίων αποθηκεύεται σε χαμηλό zoom.
Κάθε επιπλέον περιοχή που βλέπεις online αποθηκεύεται αυτόματα.
Σε μη αποθηκευμένο σημείο/zoom εμφανίζεται ουδέτερο OFFLINE πλακίδιο,
ενώ οι διαδρομές, τα WPT και το αεροπλάνο παραμένουν ορατά.

iPad – ΜΕΤΑΒΟΛΗ ΧΩΡΟΥ ΧΑΡΤΗ / ΠΑΝΕΛ
------------------------------------
Στο όριο ανάμεσα στον χάρτη και το πάνελ υπάρχει γκρι λαβή:
- iPad όρθιο: σύρε πάνω/κάτω.
- iPad οριζόντιο: σύρε αριστερά/δεξιά.
- Διπλό πάτημα στη λαβή: επαναφορά στο αρχικό μέγεθος.
Η επιλογή αποθηκεύεται αυτόματα.


ΚΙΝΗΤΟ – ΜΕΤΑΒΟΛΗ ΧΩΡΟΥ ΧΑΡΤΗ / ΠΑΝΕΛ
-------------------------------------
Τώρα η γκρι λαβή εμφανίζεται και στο κινητό.
Σύρε την πάνω ή κάτω για να μεγαλώσεις ή να μικρύνεις τον χάρτη.
Διπλό πάτημα στη λαβή: επαναφορά στο αρχικό μέγεθος.

---------------------------------

CHECK DISTANCE / SAVED POINTS / ROUTES — D416
------------------------------------------------
1. Πάτησε CHECK DISTANCE. Όταν γίνει πράσινο, κάθε tap στον χάρτη καταγράφει CHECK 1 έως CHECK 5.
2. Μπορείς επίσης να χρησιμοποιήσεις το ξεχωριστό CHECK SRCH ή το CHECK Coord.
3. Τα βελάκια στο πεδίο CHECK αλλάζουν το εμφανιζόμενο σκέλος. Οι υπολογισμοί είναι με 180 km/h.
4. Το CLR CHECK DIST x2 χρειάζεται δύο γρήγορα πατήματα και καθαρίζει μόνο τα ενεργά CHECK του χάρτη. Δεν διαγράφει τη μόνιμη λίστα.
5. Στο FIX panel, κάθε FIX / MFIX / CHECK έχει HUD, 💾 και διαγραφή.
6. Το 💾 αντιγράφει το σημείο στην ξεχωριστή λίστα «Αποθηκευμένα σημεία / Routes». Εκεί μπορείς να αλλάξεις όνομα, να δεις preview 5 δευτερολέπτων ή να το διαγράψεις.
7. Τα ονόματα της αποθηκευμένης λίστας μπορούν να γραφτούν στο SRCH του Fire και να χρησιμοποιηθούν ως θέση φωτιάς.
8. Με Create route δημιουργείς route από αποθηκευμένα σημεία, ICAO (π.χ. LGMT), πόλεις/χωριά μέσω SRCH ή συντεταγμένες.
9. Κάθε route μπορεί να ενεργοποιηθεί στον χάρτη, να γίνει preview, να τροποποιηθεί ή να διαγραφεί.
