OFFLINE ΛΕΙΤΟΥΡΓΙΑ
------------------
1. Ανέβασε όλα τα αρχεία στο GitHub Pages / hosting.
2. Άνοιξε την εφαρμογή μία φορά με internet.
3. Περίμενε να γράψει κάτω αριστερά: ONLINE · OFFLINE READY.
4. Μετά μπορείς να κλείσεις internet και να ξανανοίξεις την εφαρμογή.

Χωρίς internet λειτουργούν:
- άνοιγμα εφαρμογής,
- GPS της συσκευής,
- HUD,
- υπολογισμοί,
- WPT / διαδρομές,
- Test Mode,
- ημερολόγιο αποστολής,
- αποθηκευμένες περιοχές χάρτη.

Χωρίς internet δεν ανανεώνονται:
- METAR,
- αναζήτηση περιοχής,
- νέο αυτόματο ΤΦ.

Για ΤΦ χωρίς σύνδεση χρησιμοποιείται αποθηκευμένο ΤΦ της ίδιας ημερομηνίας
ή ζητείται Manual ΤΦ.

Ο γενικός χάρτης Ελλάδας/Βαλκανίων αποθηκεύεται σε χαμηλό zoom.
Κάθε επιπλέον περιοχή που βλέπεις online αποθηκεύεται αυτόματα.
Σε μη αποθηκευμένο σημείο/zoom εμφανίζεται ουδέτερο OFFLINE πλακίδιο,
ενώ οι διαδρομές, τα WPT και το αεροπλάνο παραμένουν ορατά.
