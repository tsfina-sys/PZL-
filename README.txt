PZL Mission Tool D459 — COMMAND / DCT INFO

Αλλαγές πάνω στη D458:
- Από την ετικέτα «Ώρα Εντολής Α/Γ» αφαιρέθηκε το «HH:MM ή 1000».
- Το παλιό γαλάζιο πλαίσιο DCT αφαιρέθηκε από τα «Στοιχεία Ρίψεων».
- Οι πληροφοριακές DCT αποστάσεις μεταφέρθηκαν μέσα στο Info.
- Εμφανίζονται καθαρά ως «DCT Φωτιά → Αφετηρία» και «DCT Αφετηρία → Φωτιά».
- Η GPS Αφετηρία αποθηκεύεται σταθερά τη στιγμή που επιλέγεται, μόνο για την ορθή απεικόνιση των συγκεκριμένων DCT πληροφοριών.
