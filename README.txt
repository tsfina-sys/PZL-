PZL Mission Tool D422 — STANDARD MAP + OPTIONAL OVERLAYS

Ο χάρτης παραμένει πάντα Standard. Πατώντας PZL MAP μπορείς να επιλέξεις ανεξάρτητα:
- κορυφές και ύψη σε ft MSL
- γραμμές μέσης / υψηλής τάσης
- κεραίες / ιστούς

Τα στοιχεία φορτώνονται μόνο όταν επιλεγούν και μόνο σε ακτίνα περίπου 100 km γύρω από Α/Γ, REFILL και FULL STOP.

Τα δεδομένα OSM/Overpass είναι βοηθητικά και όχι πιστοποιημένη βάση εμποδίων.
