D459_COMMAND_DCT_INFO

1. Η ετικέτα γράφει πλέον μόνο «Ώρα Εντολής Α/Γ:».
2. Η βοήθεια μορφής παραμένει μέσα στο πεδίο εισαγωγής ως placeholder.
3. Το πλαίσιο DCT βρίσκεται πλέον μέσα στο αναδιπλούμενο Info.
4. Προβάλλονται δύο σαφείς πληροφοριακές γραμμές:
   - DCT Φωτιά → Αφετηρία
   - DCT Αφετηρία → Φωτιά
5. Οι αποστάσεις αυτές δεν συμμετέχουν στους επιχειρησιακούς υπολογισμούς.
